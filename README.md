# Entregable-final-algebra-lineal
Para generar el scree plot se siguieron los siguientes pasos:

Se cargaron los datos de los empleados.
Se eliminaron las columnas que no corresponden a indicadores numéricos.
Se calculó la matriz de varianzas y covarianzas.
Se obtuvieron los valores y vectores propios de la matriz.
Los valores propios se ordenaron de mayor a menor.
Se calculó el porcentaje de varianza explicada por cada componente.
Se generó el scree plot.
